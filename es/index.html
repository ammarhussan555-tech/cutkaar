Descargar Cutkaar

Instálalo en tres pasos

Solo lo instalas una vez. Después Cutkaar se actualiza solo.

  1. DescargaPulsa Descargar y abre Cutkaar-Setup.exe desde tu carpeta de Descargas.
  2. Permite que se ejecuteSi Windows muestra “Windows protected your PC”, pulsa More info y luego Run anyway. Aparece porque Cutkaar es nuevo.
  3. Empieza a editarPulsa Next y luego Install. Abre Cutkaar desde el escritorio y pulsa Create project.

Preguntas

¿Cutkaar es realmente gratis?

Sí. Sin cuenta, sin marca de agua en tus vídeos y sin límite de tiempo.

¿Por qué Windows muestra un aviso?

Windows avisa de los programas nuevos que aún no se han descargado mucho. Pulsa More info y luego Run anyway. El aviso desaparece a medida que más personas usan Cutkaar.

¿Necesito internet?

No para editar ni exportar. Internet se usa para las actualizaciones, para descargar una vez el modelo de voz sin conexión y para el motor rápido de subtítulos en línea.

¿Dónde se guardan mis proyectos?

En tu propio ordenador. Cutkaar usa tus vídeos desde donde están y no los sube.

¿Cómo funcionan las actualizaciones?

Cutkaar busca una versión nueva al abrirse. Cuando está lista ves “Update ready” con un botón Restart. Tus proyectos se mantienen igual.

¿Qué necesita mi ordenador?

Windows 10 u 11 (64 bits). Para vídeos largos en 1080p o 4K, lo ideal son 8 GB de memoria o más.
