نصب در سه گام

فقط یک بار نصب می‌کنید. پس از آن Cutkaar خودش به‌روز می‌شود.

  1. دانلودروی دانلود بزنید و Cutkaar-Setup.exe را از پوشهٔ Downloads باز کنید.
  2. اجازهٔ اجرااگر ویندوز پیام “Windows protected your PC” نشان داد، روی More info و سپس Run anyway بزنید. این پیام چون Cutkaar تازه است ظاهر می‌شود.
  3. شروع ویرایشروی Next و سپس Install بزنید. Cutkaar را از دسکتاپ باز کنید و روی Create project بزنید.

ویندوز برای برنامه‌های تازه‌ای که هنوز کم دانلود شده‌اند هشدار می‌دهد. روی More info و سپس Run anyway بزنید. با استفادهٔ بیشتر مردم از Cutkaar این هشدار از بین می‌رود.

آیا اینترنت لازم است؟

پروژه‌هایم کجا ذخیره می‌شوند؟

روی رایانهٔ خودتان. Cutkaar ویدیوها را از همان جایی که هستند استفاده می‌کند و آن‌ها را بارگذاری نمی‌کند.

Cutkaar هنگام اجرا نسخهٔ تازه را بررسی می‌کند. وقتی آماده شد، “Update ready” با دکمهٔ Restart نمایش داده می‌شود. پروژه‌هایتان دست‌نخورده می‌مانند.
