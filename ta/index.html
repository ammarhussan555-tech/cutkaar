நீண்ட வீடியோக்களை உங்கள் சொந்த கணினியில் திருத்துங்கள்.

காட்சிகளைப் பிரிக்கவும், பல மொழிகளில் பேச்சிலிருந்து வசனங்களை உருவாக்கவும், தெளிவான MP4 ஆக ஏற்றுமதி செய்யவும். கணக்கு இல்லை, வாட்டர்மார்க் இல்லை.

பெரிய கோப்புகள்நீண்ட வீடியோக்களை நகலெடுக்காமலேயே திறக்கும்.
தானாகச் சேமிக்கும்திருத்தும்போதே உங்கள் திட்டங்கள் சேமிக்கப்படும்.
எப்போதும் புதியதுபுதிய பதிப்புகள் தானாக நிறுவப்படும்.

வீடியோ உருவாக்கத் தேவையான அனைத்தும்

உங்களுக்குப் பழக்கமான எடிட்டர்களைப் போன்ற டைம்லைன், அன்றாடக் கருவிகளுடன்: வெட்டுதல், வசனங்கள், உரை, இசை, ஏற்றுமதி.

உங்கள் பேச்சிலிருந்து வசனங்கள்

Cutkaar உங்கள் வீடியோவைக் கேட்டு, சரியான நேரத்துடன் வசனங்களை எழுதுகிறது. எந்தச் சொல்லையும் ஒரே கிளிக்கில் திருத்தலாம்.

  • தமிழ், ஆங்கிலம், இந்தி, உருது மற்றும் பல மொழிகள்
  • ஆன்லைன் இயந்திரம்: 15 நிமிட வீடியோ சில விநாடிகளில்
  • ஆஃப்லைன் இயந்திரம் இணையம் இல்லாமல் இயங்கும்
  • பாணிகள், முன்னிலைப்படுத்திய சொற்கள், அனிமேஷன்கள்

என்ன நடக்கிறது எனக் காட்டும் ஏற்றுமதி

480p முதல் 4K வரை, 24 முதல் 60 fps வரை தேர்வு செய்யுங்கள். வேலை நடக்கும்போது உருவாகும் சட்டகம், சதவீதம், மீதமுள்ள நேரம் தெரியும்.

  • MP4 வீடியோ, MP3 அல்லது WAV ஆடியோ, GIF மற்றும் வசனக் கோப்புகள்
  • முடிந்தவரை கிராஃபிக்ஸ் கார்டைப் பயன்படுத்தும்
  • தொடங்கும் முன் கோப்பு அளவைக் காட்டும்
காட்சிப் பிரிப்புஒவ்வொரு காட்சி மாற்றத்தையும் கண்டறிந்து கிளிப்பை வெட்டித் தரும்.
உரை மற்றும் ஸ்டிக்கர்கள்தலைப்புகள், கீழ்ப் பட்டைகள், அசையும் உரை, ஸ்டிக்கர்கள்.
எஃபெக்ட்கள் மற்றும் ஃபில்டர்கள்மாற்றங்கள், வண்ண ஃபில்டர்கள், வேகம், கீஃப்ரேம்கள்.
ஆடியோஇசை, குரல் பதிவு, ஃபேட், ஒவ்வொரு கிளிப்புக்கும் ஒலி அளவு.
திட்டங்கள்அனைத்துத் திட்டங்களுடன் முகப்புத் திரை, குப்பைத் தொட்டி, பலவற்றைத் தேர்வு செய்தல்.
தனிப்பட்டதுஉங்கள் வீடியோக்கள் உங்கள் கணினியிலேயே இருக்கும்.

Cutkaar-ஐப் பெறுங்கள்

v3.9.3 · Windows 10 மற்றும் 11 (64-bit) · இலவசம்

Cutkaar-ஐப் பதிவிறக்கு

மூன்று படிகளில் நிறுவல்

ஒருமுறை மட்டும் நிறுவுங்கள். பிறகு Cutkaar தானாகப் புதுப்பிக்கும்.

  1. பதிவிறக்குங்கள்பதிவிறக்கு என்பதைக் கிளிக் செய்து Downloads கோப்புறையிலிருந்து Cutkaar-Setup.exe-ஐத் திறக்கவும்.
  2. இயங்க அனுமதியுங்கள்Windows “Windows protected your PC” எனக் காட்டினால், More info, பிறகு Run anyway என்பதைக் கிளிக் செய்யவும். Cutkaar புதியது என்பதால் இது வருகிறது.
  3. திருத்தத் தொடங்குங்கள்Next, பிறகு Install என்பதைக் கிளிக் செய்யவும். டெஸ்க்டாப்பிலிருந்து Cutkaar-ஐத் திறந்து Create project என்பதைக் கிளிக் செய்யவும்.

கேள்விகள்

Cutkaar உண்மையிலேயே இலவசமா?

ஆம். கணக்கு இல்லை, வீடியோக்களில் வாட்டர்மார்க் இல்லை, கால வரம்பும் இல்லை.

Windows ஏன் எச்சரிக்கை காட்டுகிறது?

புதிய, இன்னும் அதிகம் பதிவிறக்கப்படாத நிரல்களுக்கு Windows எச்சரிக்கை தரும். More info, பிறகு Run anyway என்பதைக் கிளிக் செய்யவும். அதிகமானோர் Cutkaar-ஐப் பயன்படுத்தும்போது எச்சரிக்கை மறையும்.

இணையம் தேவையா?

திருத்தவும் ஏற்றுமதி செய்யவும் தேவையில்லை. புதுப்பிப்புகள், ஆஃப்லைன் பேச்சு மாதிரியை ஒருமுறை பதிவிறக்குதல், வேகமான ஆன்லைன் வசன இயந்திரம் ஆகியவற்றுக்கு மட்டும் இணையம் பயன்படும்.

என் திட்டங்கள் எங்கே சேமிக்கப்படுகின்றன?

உங்கள் சொந்தக் கணினியில். Cutkaar வீடியோக்களை அவை உள்ள இடத்திலிருந்தே பயன்படுத்தும்; எங்கும் பதிவேற்றாது.

புதுப்பிப்புகள் எப்படி வேலை செய்கின்றன?

Cutkaar திறக்கும்போது புதிய பதிப்பைச் சரிபார்க்கும். தயாரானதும் “Update ready” மற்றும் Restart பொத்தான் தோன்றும். உங்கள் திட்டங்கள் அப்படியே இருக்கும்.

என் கணினிக்கு என்ன தேவை?

Windows 10 அல்லது 11 (64-bit). நீண்ட 1080p அல்லது 4K வீடியோக்களுக்கு 8 GB அல்லது அதற்கு மேல் நினைவகம் சிறந்தது.
